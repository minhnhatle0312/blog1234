# Minh Nhật — Cybersecurity portfolio

Portfolio cá nhân của Lê Minh Nhật, giữ lại toàn bộ nội dung học tập, dự án, chứng chỉ và blog hiện có; phần mới tập trung thêm vào cybersecurity.

## Chạy trên VS Code

Yêu cầu Node.js 18 trở lên.

1. Mở thư mục này trong VS Code.
2. Nhấn `F5` và chọn `Run portfolio + open browser` để chạy và debug.
3. Hoặc mở Terminal và chạy:

```bash
npm run dev
```

Sau đó mở `http://127.0.0.1:5500`.

## Kiểm tra nhanh

```bash
npm run check
```

Server không dùng dependency bên ngoài. Có endpoint kiểm tra trạng thái tại `/__health`.
